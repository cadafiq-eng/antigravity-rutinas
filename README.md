# Antigravity — Rutinas Terapéuticas

App web progresiva (PWA) de programa terapéutico de ejercicio con ciclo de 2 semanas, reproducción de video con marcadores de tiempo personalizables, timer por fase, y detección automática de semana A/B.

## Uso
Abre `app-rutinas-v3.html` o accede via GitHub Pages.

Los videos se reproducen desde Google Drive. Para uso con videos locales, ejecutar servidor local:
```
python -m http.server 8080
```
